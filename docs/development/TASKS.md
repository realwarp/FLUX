## Release scope

The tracked release scope is the task set listed above; no P0-03 or P0-04 tasks exist. RC-05, RC-06, TUI-01, TUI-01-TOOLS, TUI-02, P2-02, and P3-02 remain under review, so this release candidate is not yet accepted. TUI-04 visual acceptance is complete. Legacy/v1.1 restoration, undocumented mock behavior, and documentation-only foundation releases are explicitly excluded.

### Manual Windows Terminal acceptance (pending)

- **Approve once:** trigger one write or patch request, approve once, and verify only the requested change occurs.
- **Deny:** trigger a mutation, deny it, and verify the target remains unchanged and FLUX reports denial.
- **Esc cancellation:** open an approval dialog, press Esc, and verify no operation occurs.
- **Resize overlays:** resize narrower and shorter with the palette, model selector, session selector, and approval dialog open; verify bounds and scrolling, and confirm approval remains unavailable when the preview cannot be reviewed.
- **Long conversation:** scroll through a long transcript and verify earlier turns and tool results remain reachable.
- **Composer/footer:** enter multiline text at a short terminal height and verify the composer and footer stay visible without overlap.

## Status rules

`TODO` means not started; `IN_PROGRESS` means actively being implemented; `REVIEW` means implementation exists and awaits lead integration review; `DONE` requires acceptance criteria, tests, integration, documentation where required, and actual evidence; `BLOCKED` records a concrete external blocker; `DEFERRED` records an intentionally excluded feature and reason.
